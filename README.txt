CUSTOM HOODIE MAKER - By BeatrixKiddo
----------

1. Put your two transparent logos here:
       logos\back.png
       logos\front.png

2. Run:
       Run_Batch_Logo_Baker.bat

3. DONE!:
	  Depends, if you want to change the default logo placement then choose option 2 in Run_Batch_Logo_Baker.bat


1. Pick the base as your reference texture, draw:
       RED   = back logo
       GREEN = front logo

2. After both boxes:
       Q / E       rotate BACK
       A / D       rotate FRONT
       Shift+key   rotate 5 degrees
       R           redraw both
       Enter       save and bake

3. Pack the folder:
       Yourname_Custom_Hoodie_Mod\ (CHANGE THIS -> THIS WILL BE THE PBO NAME)
Creates the texure paa files and is ready for ADDON BUILDER -> DS UTIL -> then you can either take the .pbo's to your server pack and publish or publish it as a mod by it self, to do that choose publisher in DayZTools, create the following folder:
--------------------------------------------------
\Yourname_Custom_Hoodie_Mod
|
\Addons
	|  Yourname_Custom_Hoodie_Mod.pbo
	|  Yourname_Custom_Hoodie_Mod.bsigin.pbo
|\Keys
	|BeatrixKiddo.bikey

--------------------------------------------------

Then select this folder as the publisher folder to upload and you are done!
